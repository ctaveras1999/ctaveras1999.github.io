{%- comment -%} Lists every page whose front matter has `section: `, newest first. Usage: {% include page-list.html section="blog" %} Each listed page needs `date:`; `category:`, `description:`, and `tags:` are optional (a page with tags shows its tags instead of its category label) (`description` is also what search engines and link previews show). Tags: `tags: [Personal, Lists]`. A row of all tags appears above the list; clicking a tag (here or under a post) shows only posts with that tag. The filter is kept in the address (e.g. /blog/?tag=Personal), so post pages can link to it.
